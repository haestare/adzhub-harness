Como o harness funciona

memóriaSupercérebro (grafo + linha do tempo). Hidratado como ambiente antes do loop, não chamado às cegas.
apiAPIs (Meta, CRM). Tools que o agente chama no loop ReAct quando precisa de dado cru.
appApps de metodologia. Skills encapsuladas; o harness chama o app, não reimplementa a metodologia.
custoTokens por chamada. Um turno de agente são N chamadas, e cada uma reenvia a conversa mais as observações: por isso a entrada cresce passo a passo.
